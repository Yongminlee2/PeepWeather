# 날씨 비교 (Weather Compare) 설계

작성일: 2026-10-11

## 1. 목적

예보는 기관마다 다르다. 이 앱은 **내 위치(또는 저장한 도시)의 날씨·예보·미세먼지·태풍을 여러 기관 것으로 나란히 보여주고, 기관끼리 엇갈리는 곳을 표시**한다. 사용자는 "어느 예보가 맞을지" 스스로 판단할 수 있다.

- 대상: 전 세계 사용자 (한국에 있으면 한국 기관이 자동 추가)
- 플랫폼: Flutter 단일 코드. **안드로이드 먼저 출시**, 아이폰은 맥/빌드 서비스가 준비되면 출시 (코드는 처음부터 iOS 호환으로 작성)
- 비용: 상업 이용 가능한 **무료** 자료만 사용
- 구조: 서버 없이 **앱이 각 기관에 직접 요청**

**원칙:** 예보·미세먼지·태풍 모두 **세계 어디서든 최소 3곳**을 나란히 보여준다. 정리하면 다음과 같다.

| 항목 | 전 세계 공통 | 한국에서 추가 | 미국에서 추가 |
|---|---|---|---|
| 예보 | MET Norway, OpenWeather, WeatherAPI, Visual Crossing | 기상청 | NWS |
| 미세먼지 | OpenWeather, WeatherAPI, OpenAQ | 에어코리아 | |
| 태풍 | GDACS, NHC, JTWC (해역에 맞는 곳이 응답) | 기상청 태풍정보 | |
| 위성 구름 | NASA 정지위성 적외선·가시광, NASA 극궤도 실사, OpenWeather 구름·강수 | 천리안 2A호 | |

**뺀 곳과 이유:** Open-Meteo, Tomorrow.io, WAQI(aqicn)는 무료로 쓰려면 비상업용이어야 한다. Meteosource는 무료 상업 이용 여부가 자기 문서끼리 엇갈린다. 유료로 바꿀 때 다시 검토한다.

- **나라 판정:** OpenWeather 역지오코딩의 국가 코드가 `KR`이면 한국 출처 3개를, `US`이면 NWS를 추가한다. 같은 호출로 화면에 띄울 지명도 얻는다.
- **키 보관:** 키는 `keys.json`에 두고 `--dart-define-from-file`로 빌드에 넣는다. `keys.json`은 git에 올리지 않는다. 앱 안의 키는 마음먹으면 꺼낼 수 있다. 서버 없는 구조를 택하면서 감수한 점이고, 사용자가 늘면 중간 서버로 옮긴다.

## 3. 화면

화면 하나를 위아래로 스크롤한다. 저장한 장소가 여럿이면 옆으로 넘겨서 장소를 바꾼다. 첫 장은 항상 현재 위치다.

1. **머리:** 지명(예: "서울 강남구"), 기준 시각, 기관별 현재 날씨 한 줄(아이콘, 기온, 하늘 상태)
2. **시간별 비교표:** 앞으로 24시간을 3시간 간격으로 보여준다(현지 0·3·6…시). 행은 기관, 열은 시각이고, 칸에는 아이콘·기온·비 확률이 들어간다. 기관마다 해당 시각에 가장 가까운 값을 넣고, 해당 시각 값이 없으면 "—"로 둔다.
3. **날짜별 비교:** 앞으로 5일 동안 기관별 최고·최저 기온, 아이콘, 비 확률을 보여준다. 기관이 예보하지 않는 날은 "—"(예: WeatherAPI·기상청은 3일까지).
4. **엇갈림 표시:** 같은 시각·같은 날에 아래 조건 중 하나가 맞으면 그 열에 "예보가 엇갈려요" 표시를 한다.
   - 기관 간 기온 차(최고 − 최저)가 3°C를 넘는다
   - 어느 기관은 비 확률이 50% 이상인데, 다른 기관은 20% 미만이다
5. **미세먼지 비교:** 기관별 PM10·PM2.5 수치와 등급 색(좋음/보통/나쁨/매우나쁨). 등급은 전 세계 공통으로 한국 환경부 기준을 쓴다.
   - PM10: 0–30 좋음, 31–80 보통, 81–150 나쁨, 151 이상 매우나쁨
   - PM2.5: 0–15 좋음, 16–35 보통, 36–75 나쁨, 76 이상 매우나쁨
6. **태풍:** 1,000km 안에 열대저기압이 있으면 경고 카드(이름, 거리, 등급·풍속)를 띄우고, 없으면 "근처 태풍 없음"을 보여준다. 카드 하나에 태풍 하나를 담고, 그 안에 기관별(GDACS·NHC·JTWC·기상청) 위치·강도를 나란히 놓는다. 같은 태풍인지는 이름으로 판정하고, 이름이 다르면 300km 안에 있는지로 판정한다.
7. **위성 구름 지도:** 내 위치를 가운데 둔 지도에 위성 영상을 깔고, 위쪽 탭으로 출처를 바꿔 본다. 지도 확대·이동이 되고, 재생 버튼을 누르면 최근 2시간이 움직인다.
   - **NASA 정지위성 적외선:** 내 경도에 맞는 위성을 고른다(GOES-West, GOES-East, Himawari). 유럽·아프리카(경도 −30°~60°)는 GIBS에 정지위성 레이어가 없어서 극궤도 실사를 먼저 보여준다. 10분 간격이고 밤에도 보인다. 구름 꼭대기 온도로 비구름을 짐작할 수 있다.
   - **NASA 정지위성 가시광:** 위와 같은 위성의 낮 사진이다. 밤이면 "밤에는 적외선을 보세요"라고 안내한다.
   - **NASA 극궤도 실사(MODIS/VIIRS):** 하루 한 장인 고해상도 실제 색 사진이다.
   - **OpenWeather 구름·강수 지도:** 예보 모델이 계산한 구름과 비 분포다.
   - **한국에 있을 때 기상청 천리안 2A호:** 공공데이터포털 위성영상 조회서비스로 받은 한반도 영상을 지도 대신 그림으로 보여준다.
   - 해안선과 국경은 NASA GIBS 참조 레이어를 위에 겹친다. OSM 같은 별도 바탕지도는 쓰지 않는다(OSM 타일 사용 정책 문제).
8. **출처 표기:** 화면 맨 아래에 각 기관이 요구한 문구와 링크를 단다.
9. **조작:** 아래로 당겨서 새로고침한다. 우상단에서 도시 검색과 설정을 연다.

**도시 검색:** OpenWeather Geocoding으로 검색하고, 고른 도시를 저장 목록에 넣는다. 저장 목록은 삭제할 수 있다.

**설정:** 섭씨/화씨, 알림 종류별 켜기/끄기, 출처 표기, 개인정보처리방침 링크.

**언어:** 폰 언어를 따라 한국어/영어로 표시한다. 그 밖의 언어는 영어로 표시한다.

## 4. 구조

```
lib/
  main.dart
  models.dart            공통 모양: Current, HourSlot, DaySlot, Air, Cyclone, SourceResult
  sources/               출처마다 파일 하나 ("번역기"): 요청 → 공통 모양으로 변환
    met_norway.dart
    openweather.dart
    weatherapi.dart
    kma.dart             기상청 단기예보 + 위경도→격자 변환
    airkorea.dart        에어코리아 + 위경도→TM 변환
    kma_typhoon.dart
    gdacs.dart
    visual_crossing.dart
    openaq.dart
    nws.dart
    nhc.dart
    jtwc.dart
    satellite.dart       위성 레이어 목록(타일 주소·시각), 천리안 영상 조회
  compare.dart           엇갈림 판정, 미세먼지 등급, 거리 계산(하버사인)
  repository.dart        출처 병렬 호출, 30분 저장본, 한국 판정
  ui/                    화면
  background.dart        알림·위젯 갱신 작업
android/.../widget       안드로이드 위젯 레이아웃
```

- **번역기 규칙:** 각 출처는 `Future<SourceResult> fetch(Place)` 하나만 내보낸다. `SourceResult`에는 출처 이름, 성공 시 데이터, 실패 시 이유(키 없음, 한도 초과, 네트워크, 기타)가 담긴다.
- **상태 관리:** 별도 라이브러리 없이 `ChangeNotifier`를 쓴다.
- **저장:** 설정과 저장 도시는 `shared_preferences`, 출처별 마지막 응답 원문은 앱 저장소 파일(요청 주소별)에 둔다. 저장본은 다시 읽어서 해석하므로 따로 변환 코드가 필요 없다.
- **사용 패키지:** `flutter_map`(위성 타일 지도), `http`, `geolocator`, `shared_preferences`, `workmanager`, `flutter_local_notifications`, `home_widget`, `flutter_localizations`/`intl`

## 5. 흐름

1. 앱을 켜면 위치 권한을 요청한다. 허용하면 위치를 받고, 거절하면 도시 검색 화면으로 안내한다.
2. 역지오코딩으로 지명과 국가를 얻고, 국가에 맞춰 출처 목록을 정한다.
3. 출처별 저장본이 30분 이내면 저장본을 보여주고, 아니면 모든 출처를 동시에 요청한다. 실패한 출처는 직전 저장본으로 채우거나, 저장본이 없으면 실패 이유를 보여준다.
4. 지금 보고 있는 장소만 요청한다. 넘겨 본 장소는 그때 요청한다.

## 6. 알림과 위젯 (안드로이드)

- `workmanager`로 2시간마다 **앱을 켰을 때 마지막으로 잡은 위치**(없으면 첫 저장 도시)를 확인한다. 백그라운드 위치 권한은 받지 않는다(Play 심사 부담).
- 알림 조건(종류별로 켜고 끌 수 있음):
  - **비:** 앞으로 12시간 안에 어느 기관이든 비 확률 60% 이상. 같은 날 같은 비 알림은 한 번만 보낸다.
  - **미세먼지:** 어느 기관이든 "나쁨" 이상. 하루 한 번만 보낸다.
  - **태풍:** 500km 안에 열대저기압. 태풍마다 한 번 보내고, 거리가 절반으로 줄면 한 번 더 보낸다.
- 백그라운드 확인은 횟수를 아끼려고 MET Norway, OpenWeather, OpenAQ, 태풍 출처(GDACS·NHC·JTWC)만 부르고, 한국이면 에어코리아도 부른다. 알림 조건은 이 출처들 중 하나만 맞아도 성립한다. WeatherAPI와 Visual Crossing은 한도가 작아 앱을 켰을 때만 부른다.
- **위젯:** 기관별 현재 기온을 작게 나란히 보여준다. 앱을 새로고침할 때와 백그라운드 확인 때 함께 갱신한다.
- **아이폰:** 알림은 iOS 백그라운드 갱신(BGAppRefreshTask)으로 같은 코드를 쓰지만 실행 시점은 iOS가 정한다. 아이폰 위젯은 SwiftUI(WidgetKit) `ios/CompareWidget/` 로 만들었다(2026-10-14).

| 상황 | 표시 |
|---|---|
| 위치 권한 거절 또는 위치를 못 잡음 | "도시를 검색해서 추가하세요" + 도시 검색 버튼 + 설정 열기 버튼 |
| 키 없음 | 그 출처 칸에만 "설정 필요" |
| 키가 틀림(또는 아직 활성화 전) | 그 출처 칸에만 "키 오류" |
| 한도 초과 (HTTP 429 등) | 그 출처 칸에만 "오늘 한도 초과" |
| 네트워크 없음 | 저장본을 "○시 ○분 기준"으로 표시, 저장본이 없으면 "인터넷 연결 확인" |
| 응답 형식이 이상함 | 그 출처 칸에만 "못 가져옴" |

한 출처가 실패해도 다른 출처는 그대로 보여준다.

## 8. 테스트

- 각 출처의 실제 응답을 `test/fixtures/`에 저장해 두고, 번역기가 공통 모양으로 올바르게 바꾸는지 확인한다(인터넷 없이 실행).
- 기상청 격자 변환과 TM 변환은 알려진 좌표 쌍(예: 서울시청 → nx 60, ny 127)으로 확인한다.
- 엇갈림 판정, 미세먼지 등급 경계값, 하버사인 거리, 알림 중복 방지를 테스트한다.
- 마지막에는 실기기에서 직접 켜서 확인한다. 설치는 사용자가 요청할 때만 한다.
