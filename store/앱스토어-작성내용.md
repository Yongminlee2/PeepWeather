```
Weather Compare shows forecasts for the same place and time from several weather providers side by side and marks where they disagree. No account or sign-in.

- Location: "While Using" approximate location is used only to fetch the forecast for where the user is. If declined, tap the search icon (top right) and add a city, or pick one of the suggested cities.
- Notifications: optional alerts for rain, bad air quality and approaching tropical cyclones (Settings > each kind can be turned off).
- Background App Refresh: about every 2 hours (when iOS allows) the app re-checks the last location found while the app was open, to send those alerts and refresh the home-screen widget. No background location is used.
- Home-screen widget: "Weather Compare" (small/medium) shows each provider's current temperature.
- Data comes from public weather services (KMA, AirKorea, MET Norway, Open-Meteo, OpenWeather, WeatherAPI.com, Visual Crossing, OpenAQ, NOAA, JTWC, GDACS, NASA GIBS, EUMETSAT); each source is credited in the app.
```
